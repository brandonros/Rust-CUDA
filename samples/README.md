# Rust-Cuda Samples

These are the Rust-Cuda port of the samples from Nvidia's [cuda-samples](https://github.com/NVIDIA/cuda-samples/tree/master/Samples) repository.

Cargo builds the compiler backend dependency automatically. See the
[build instructions](../README.md#building-kernels) for feature selection.
